주문

결제가 확인되면 새 코드 주문은 토큰 보내기, 충전 주문은 충전하기를 누르세요. 코드나 충전 알림이 주문한 이메일로 바로 갑니다. 성균관컨설팅 결제 페이지에서 결제한 주문은 결제 내역의 주문자 이메일 · 금액으로 맞춰 보세요.

토큰 자동 발송: 성균관컨설팅(아임웹)에서 카피휴먼 토큰 상품이 결제되면 카피휴먼 서버가 바로 16자리 코드를 만들어 주문자 이메일로 보냅니다(같은 주문은 한 번만). 상품은 체험 30토큰 3,000원(아임웹 34) · 라이트 150토큰 10,000원(35) · 프로 500토큰 30,000원(36, 추천) · 프리미엄 1,100토큰 50,000원(37). 보낸 코드는 아래 코드 목록의 메모 ‘아임웹 결제 자동 · 주문 …’으로 보입니다. 주문자 이메일이 없거나 메일이 실패하면 운영 메일(copyhuman2@gmail.com)로 알림이 가니, 그 주문만 직접 만들기로 보내 주세요.

단위(10.24부터): 이 화면의 토큰은 1토큰 = 100원입니다. 손님 메일은 10.30부터 토큰으로 갑니다. 서버 기록은 크레딧(1크레딧 = 10원)이라 이 화면이 토큰으로 바꿔 보여 주고, 이 화면에 넣는 토큰 수는 크레딧으로 바꿔 서버에 보냅니다.

토큰 코드 직접 만들기

계좌 이체 확인, 보상, 쿠폰처럼 주문 없이 줄 때 씁니다. 받는 메일을 적으면 코드가 그 메일로 가고, 비워 두면 코드를 이 화면에만 한 번 보여 드립니다(최대 20개). 유효기간은 만든 날부터 5년입니다.

충전

쓰고 있는 토큰 코드에 더합니다. 상품을 고르면 그 상품의 토큰(더 받는 토큰 포함)이 환불 기준과 함께 기록되고, 토큰 수만 넣으면 보상 · 지급으로 기록됩니다(환불 대상 아님).

차감

잘못 충전한 토큰을 바로잡거나 환불한 만큼 뺄 때 씁니다. 왜 뺀 토큰인지 메모를 꼭 적어 주세요.

토큰 코드

원래 코드는 저장하지 않습니다(해시만). 코드를 잃어버린 분께는 새 코드를 만들어 남은 토큰만큼 충전해 보내고, 이전 코드는 중지하세요. 예전 이용권도 여기에 함께 보입니다.

결제

토큰 결제는 공식 결제처 성균관컨설팅으로 연결합니다. 상품별 결제 페이지 주소(성균관컨설팅 쇼핑몰)는 스크립트 속성 AM_BUY_LINKS(예: {"c30":"https://skkc.co.kr/shop_view?idx=36&kaiec_buy=1"})에 넣거나 사이트 설정(ch-config.js)의 상품 번호를 쓰면, 주문한 분에게 '성균관컨설팅에서 결제하기' 단추가 보입니다. 결제 안내 글은 AM_PAY_GUIDE로 바꿉니다. 바로 결제(토스페이먼츠)는 TOSS_CLIENT_KEY, TOSS_SECRET_KEY로 켭니다.

보안

관리 링크가 새어 나갔다면 모든 관리 링크를 끊으세요. 그동안 보낸 링크가 모두 무효가 되고, 새 링크가 운영자 메일로 갑니다.
