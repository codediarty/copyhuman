결제 방법

결제부터 이어서 쓰기까지, 네 단계

  1. 토큰 고르기

    검사 결과 화면이나 이 페이지에서 충전할 토큰을 고릅니다. 글 길이에 맞는 묶음을 먼저 추천해 드립니다.

  2. 이 화면에서 바로 결제

    코드 받을 이메일을 적으면 운영사 성균관컨설팅의 토스페이먼츠 결제창이 열립니다. 회원가입은 필요 없습니다.

  3. 성균관컨설팅에서 결제

    운영사 성균관컨설팅의 안전결제로 회원가입 없이 토스페이 · 카드 · 계좌이체로 결제합니다.

  4. 바로 코드 받기

    결제가 끝나면 그 자리에서 16자리 토큰 코드가 열리고, 적어 주신 이메일로도 보내 드립니다.

  5. 메일로 코드 받기

    결제가 확인되면 주문서의 결과 수령 이메일로 16자리 토큰 코드를 보내 드립니다(영업일 하루 안).

  6. 하던 일 그대로 이어서

    코드는 이 브라우저에 저장되고, 결제 전에 누른 전체 결과 보기나 휴머나이징이 넣어 두었던 글로 바로 이어서 진행됩니다.

  7. 코드 넣고 이어서

    위쪽의 토큰 코드 단추나 결과 화면에 코드를 넣으면, 넣어 두었던 글로 바로 이어서 진행합니다.

영수증 · 세금계산서

영수증과 세금계산서는 운영사 성균관컨설팅 이름으로 발행되고, 카드 명세서에도 성균관컨설팅으로 표시됩니다. 결제 페이지 상품명에는 엔진 제공사 AIMarker 이름이 함께 보일 수 있습니다.

여러 기기에서

토큰 코드는 로그인 대신 쓰는 열쇠입니다. 노트북에서 산 코드를 휴대폰에 넣어도 같은 토큰을 씁니다. 코드를 아는 사람은 누구나 쓸 수 있으니 잘 보관하세요.

자주 묻는 질문

요금과 결제에 대해 자주 묻는 것

어떤 묶음을 사야 하나요?

레포트 한두 편이면 체험(30토큰)으로 충분합니다. 한 학기 과제나 자기소개서 시즌에는 라이트(150토큰), 논문 한 편 전체를 다듬는다면 프로(500토큰)가 맞습니다. 검사 결과 화면에서 충전 창을 열면 그 글에 맞는 묶음을 먼저 골라 드립니다.

남은 토큰은 언제까지 쓸 수 있나요?

토큰은 충전일부터 5년 동안 같은 코드로 씁니다. 쓰던 코드에 더 충전하고 싶다면 충전 창에서 '지금 쓰는 코드에 토큰 더하기'를 고르세요.결제 뒤 contact@skkc.co.kr로 기존 코드의 끝 4자리를 알려 주세요.

검사하다 오류가 나면 토큰이 빠지나요?

처리하지 못한 요청은 토큰이 빠지지 않습니다. 결과를 받은 만큼만 빠지고, 남은 토큰은 결과 화면과 위쪽 토큰 단추에서 확인할 수 있습니다.

연구실이나 학과 단위로 살 수 있나요?

프리미엄(1,100토큰)을 사서 같은 코드를 함께 쓰면 됩니다. 더 많은 양이 필요하거나 기관 이름으로 계좌이체 · 세금계산서가 필요하면 실시간 상담이나 contact@skkc.co.kr로 문의하세요.

왜 결제 페이지가 성균관컨설팅인가요?

카피휴먼은 성균관컨설팅이 운영하는 서비스입니다. 그래서 결제와 영수증, 세금계산서는 성균관컨설팅이 처리합니다. 성균관컨설팅은 사업자등록번호 272-32-01885, 통신판매업 신고 제2026-경기송탄-0622호로 등록된 사업자입니다.
