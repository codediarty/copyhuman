시간이 부족할 때

제출일이 가까워 직접 고칠 시간이 없을 때. 분량과 마감일을 알려 주시면 가능한 일정부터 안내합니다.

자주 묻는 질문

전문가 휴머나이징에 대해 자주 묻는 것

비용은 어떻게 정해지나요?

고칠 글자 수, 결과확인서에 표시된 영역의 양, 마감일로 정합니다. 결과확인서나 원고를 상담 때 보여 주시면 정확한 견적을 드립니다.

얼마나 걸리나요?

분량과 전공, 마감일에 따라 다릅니다. 상담 때 가능한 일정을 먼저 알려 드리고, 일정에 맞춰 진행합니다.

제 논문이 외부로 나가지 않나요?

작업에 필요한 파일만 받고, 비밀 유지와 파일 보관 방법은 상담 때 정해 안내해 드립니다.

수정 뒤 카피킬러 결과가 보장되나요?

특정 검사기의 점수나 통과는 보장할 수 없습니다. 대신 수정 뒤 다시 검사한 결과를 함께 드려, 어디가 얼마나 줄었는지 확인할 수 있게 합니다.
