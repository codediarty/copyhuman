개인정보처리방침

시행일 2026년 10월 28일운영 성균관컨설팅

성균관컨설팅(이하 '회사')은 카피휴먼 서비스를 운영하며 개인정보 보호법을 지킵니다. 카피휴먼은 회원가입 없이 운영하고, 서비스에 꼭 필요한 정보만 처리합니다.

1. 처리하는 정보와 목적

구분처리하는 정보목적보관
검사 · 휴머나이징이용자가 넣은 글AI 생성 검사와 휴머나이징 처리처리 뒤 응답과 함께 버림(저장하지 않음)
올린 파일한글 · 워드 · PDF 파일, 카피킬러 결과확인서글 꺼내기이용자의 브라우저 안에서만 읽음(서버로 보내지 않음)
토큰 코드코드의 해시, 남은 토큰, 사용 기록토큰 확인과 차감토큰을 다 쓰거나 환불할 때까지
요청 식별값브라우저에서 만든 임의의 값, 접속한 사이트 주소요청 구분, 오남용 방지처리 기록 보관 기간 동안
결제 · 주문주문자 이름, 이메일, 연락처, 주문 번호, 결제 결과(카드 번호 등 결제 수단 정보는 결제 대행사가 처리)결제, 토큰 코드 발급 · 발송, 영수증 · 세금계산서, 환불전자상거래법에 따라 5년
문의 · 상담이름, 연락처, 상담 내용문의 답변, 전문가 휴머나이징 견적상담 종료 뒤 3년

결과확인서의 학번 · 이메일 · 성명 · 소속 같은 머리 정보는 읽지 않습니다.

2. 이용자의 브라우저에 저장하는 것

  • ch_pass: 넣은 토큰 코드. 다음 방문 때 다시 넣지 않도록 저장합니다.
  • ch_cid: 요청을 구분하는 임의의 값. 이용자를 알아볼 수 있는 정보는 담지 않습니다.
  • ch_draft: 결제하러 다녀오는 동안 넣어 둔 글. 탭을 닫으면 지워지는 저장소에 6시간까지만 둡니다.

브라우저 설정에서 사이트 데이터를 지우면 모두 지워집니다. 공용 컴퓨터에서는 쓰고 나서 지워 주세요.

3. 처리를 맡기거나 함께 쓰는 곳

  • 카피휴먼 서버(성균관컨설팅 운영, Google Apps Script 기반): 검사와 휴머나이징 처리, 토큰 확인, 토큰 코드 메일 발송(Gmail)
  • 성균관컨설팅 결제 페이지(아임웹)와 결제 대행사(토스페이먼츠 등): 결제와 주문 처리
  • 채널톡: 실시간 상담
  • GitHub Pages: 웹사이트 호스팅(접속 기록)
  • Google Fonts: 웹 글꼴 제공(글꼴을 불러올 때 접속 정보가 전달될 수 있음)
  • jsDelivr: 웹 글꼴(Pretendard) 제공(글꼴을 불러올 때 접속 정보가 전달될 수 있음)

회사는 이용자의 글과 개인정보를 팔거나 광고에 쓰지 않습니다. 현재 방문 통계 도구는 쓰지 않으며, 쓰게 되면 이 방침을 먼저 고쳐 알립니다.

4. 파기

보관 기간이 끝나거나 목적을 이룬 정보는 지체 없이 지웁니다. 전자 파일은 되살릴 수 없는 방법으로 지우고, 종이 문서는 분쇄합니다.

5. 이용자의 권리

이용자는 회사가 처리하는 자신의 개인정보를 열람하거나 고치거나 지우도록, 또는 처리를 멈추도록 요구할 수 있습니다. 아래 연락처로 요청하면 지체 없이 처리합니다.

6. 안전 조치

모든 통신은 암호화 연결(HTTPS)로 합니다. 토큰 코드는 해시로만 기록하고, 개인정보를 다루는 사람을 최소로 정해 관리합니다.
